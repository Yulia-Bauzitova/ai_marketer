ПОРЯДОК: ЗАГРУЗИТЬ, СОБРАТЬ И УСТАНОВИТЬ ПРИЛОЖЕНИЕ
=================================================

Всего 8 этапов, примерно 15 минут вместе с ожиданием сборки.
Что понадобится: аккаунт GitHub (бесплатный) и распакованный архив
ai_marketer_download.zip. Python, Android Studio и командная строка
не нужны.

------------------------------------------------------------------
ЭТАП 0. ПОДГОТОВКА (3 минуты)
------------------------------------------------------------------
   1.1. Скачайте ai_marketer_download.zip и распакуйте в папку без
        русских букв в пути, например: C:\ai_marketer
        Правый щелчок по архиву → «Извлечь все» → «Извлечь».
   1.2. Откройте папку и убедитесь, что внутри есть:
           ai_marketer_one.py
           start_one.bat
           start_one_phone.bat
           build_exe.bat
           android\            (папка)
           .github\            (папка, может быть в конце списка)
           СКАЧАТЬ_ПРИЛОЖЕНИЕ.txt
        Если папки .github нет — распаковка «потеряла» скрытую папку.
        Распакуйте заново через 7-Zip или Bandizip.
   1.3. Заведите аккаунт на github.com (если ещё нет) и войдите.

------------------------------------------------------------------
ЭТАП 1. СОЗДАТЬ РЕПОЗИТОРИЙ (1 минута)
------------------------------------------------------------------
   2.1. github.com → зелёная кнопка «New» (или «+» → New repository).
   2.2. Repository name: ai-marketer
   2.3. Видимость: Public (сборка бесплатна без ограничений)
        или Private (тоже бесплатно, но минуты сборки из общего лимита).
   2.4. Галочки «Add a README file» и «Add .gitignore» НЕ ставьте:
        эти файлы уже есть в архиве, лишние вызовут конфликт.
   2.5. «Create repository».

------------------------------------------------------------------
ЭТАП 2. ЗАГРУЗИТЬ ФАЙЛЫ (3 минуты)
------------------------------------------------------------------
   ВАРИАНТ А — через сайт, без командной строки:
   3.1. На странице пустого репозитория нажмите
        «uploading an existing file».
   3.2. Откройте папку C:\ai_marketer в проводнике, выделите ВСЁ
        (Ctrl+A) и перетащите в окно браузера.
        Важно: перетаскивать нужно и папки android и .github —
        структура сохранится сама.
   3.3. Внизу нажмите «Commit changes».
   3.4. Проверьте: на главной странице репозитория должны быть видны
        папки android и .github, файл ai_marketer_one.py.

   ВАРИАНТ Б — через git (если установлен):
        cd C:\ai_marketer
        git init
        git add .
        git commit -m "AI-marketer 24/7"
        git branch -M main
        git remote add origin https://github.com/ВАШ_ЛОГИН/ai-marketer.git
        git push -u origin main
      Пароль не подойдёт: нужен токен (Settings → Developer settings →
      Personal access tokens → Tokens (classic) → Generate new token,
      права repo). Токен вставляется вместо пароля.

   ЕСЛИ .github НЕ ЗАГРУЗИЛСЯ (частая проблема веб-загрузки):
        Add file → Create new file → в поле имени напишите ровно:
           .github/workflows/windows-exe.yml
        GitHub сам создаст папки. Вставьте содержимое файла
        .github\workflows\windows-exe.yml из архива → Commit.
        Повторите то же для android-apk.yml.

------------------------------------------------------------------
ЭТАП 3. ПРОВЕРИТЬ ЗАПУСК СБОРКИ (1 минута + 2–4 минуты ожидания)
------------------------------------------------------------------
   4.1. Вкладка «Actions» вверху репозитория.
   4.2. Должны идти два запуска: «Windows EXE» и «Android APK».
        Если вкладка пустая: Settings → Actions → General →
        «Allow all actions» → Save, затем Actions → выберите workflow →
        «Run workflow».
   4.3. Жёлтый кружок = идёт сборка. Зелёная галочка = готово.
        Красный крестик = ошибка, см. раздел «ЕСЛИ СБОРКА УПАЛА».

------------------------------------------------------------------
ЭТАП 4. СКАЧАТЬ ГОТОВЫЕ ФАЙЛЫ (1 минута)
------------------------------------------------------------------
   5.1. Actions → откройте запуск «Windows EXE» (последний сверху).
   5.2. Прокрутите вниз до блока «Artifacts».
   5.3. Нажмите «AI-Marketer-Windows» — скачается zip-архив
        (так GitHub отдаёт артефакты, это нормально).
   5.4. Распакуйте: внутри один файл AI_Marketer.exe.
   5.5. Повторите для «Android APK» → «AI-Marketer-Android» →
        внутри app-debug.apk.

------------------------------------------------------------------
ЭТАП 5. УСТАНОВКА НА WINDOWS
------------------------------------------------------------------
   6.1. Положите AI_Marketer.exe в постоянную папку, например
        C:\ai_marketer_app (не в «Загрузки»: рядом создаются данные).
   6.2. Двойной щелчок. SmartScreen скажет «Неизвестный издатель»:
        «Подробнее» → «Выполнить в любом случае» (файл не подписан
        сертификатом, это ожидаемо).
   6.3. Откроется чёрное окно с рамкой и адресом, браузер откроется сам:
           http://127.0.0.1:8081
   6.4. Windows спросит про брандмауэр — разрешите доступ
        в частных сетях (нужно, чтобы заходил телефон).
   6.5. Окно консоли не закрывайте: это и есть работающее приложение.
        Остановка — Ctrl+C или закрыть окно.

------------------------------------------------------------------
ЭТАП 6. УСТАНОВКА НА ТЕЛЕФОН
------------------------------------------------------------------
   7.1. Перекиньте app-debug.apk на телефон: USB-кабелем, почтой,
        Telegram «Избранное» или Google Drive.
   7.2. Откройте файл на телефоне. Android скажет, что установка
        из этого источника запрещена → «Настройки» → разрешить
        для приложения, из которого открываете файл (Файлы/Chrome).
   7.3. «Установить» → «Открыть».
   7.4. Приложение спросит адрес кабинета. Возьмите его из окна
        программы на компьютере: строка «С телефона (тот же Wi-Fi)»,
        вид http://192.168.1.10:8081 — введите и нажмите «Открыть».
   7.5. Телефон и компьютер должны быть в одной сети Wi-Fi,
        компьютер включён, приложение на нём запущено.

------------------------------------------------------------------
ЭТАП 7. ПЕРВЫЙ ЗАПУСК И НАСТРОЙКА (5 минут)
------------------------------------------------------------------
   8.1. В браузере/приложении откроется форма «Первый запуск».
   8.2. Имя бота: например @my_marketer_bot (в Telegram у @BotFather
        команда /newbot выдаёт имя и токен).
   8.3. Токен бота: строка вида 123456789:AAH... — вставьте целиком.
   8.4. Название компании, пароль администратора (минимум 6 символов).
   8.5. Канал публикации — можно пропустить и указать позже.
   8.6. Режим нейросети:
           «Без нейросети»     — работает сразу, тексты по шаблонам;
           «Облако по ключу»   — нужен ключ OpenRouter/VseGPT;
           «Локальная модель»  — нужен установленный Ollama.
   8.7. «Сохранить и войти» → откроется кабинет.
   8.8. Проверки в разделе «Настройки»:
           «Проверить бота»     — должен ответить @имя;
           «Проверить нейросеть» — покажет ответ модели или причину.
   8.9. Проверьте работу: напишите боту в Telegram любое сообщение —
        он пришлёт пост с картинкой и кнопки согласования.

------------------------------------------------------------------
ЭТАП 8. ОБНОВЛЕНИЕ ПОЗЖЕ
------------------------------------------------------------------
   9.1. Изменили ai_marketer_one.py в репозитории (или загрузили новую
        версию файла кнопкой «Add file → Upload files») → Commit.
   9.2. Actions пересоберёт приложение автоматически.
   9.3. Скачайте новый артефакт, замените .exe (или установите apk
        поверх старого — данные сохранятся, они лежат отдельно).

------------------------------------------------------------------
ЕСЛИ СБОРКА УПАЛА
------------------------------------------------------------------
   Actions → красный запуск → откройте шаг с красным крестом,
   посмотрите последние строки. Частые случаи:

   «gradle: command not found» или ошибка AGP
      В android/build.gradle замените версию на 8.2.2,
      в .github/workflows/android-apk.yml gradle-version на «8.6».
      Commit → сборка перезапустится.

   «No such file or directory: ai_marketer_one.py»
      Файл лежит не в корне репозитория. Проверьте, что он на главной
      странице, а не внутри вложенной папки.

   «if-no-files-found: error» у Windows
      PyInstaller не собрал файл: смотрите шаг «Build single file»,
      там будет причина (обычно синтаксис или нехватка памяти).

   Сборка не запускается совсем
      Settings → Actions → General → Allow all actions → Save.

------------------------------------------------------------------
ЕСЛИ GITHUB НЕ ХОЧЕТСЯ
------------------------------------------------------------------
   Приложение работает и без сборки:
      Windows: start_one.bat (нужен Python 3.9+ с python.org,
               галочка «Add Python to PATH»)
      Телефон: start_one_phone.bat на ПК, затем открыть адрес
               в браузере телефона и выбрать
               «Добавить на главный экран».
