КАК СКАЧАТЬ ГОТОВОЕ ПРИЛОЖЕНИЕ
==============================

Коротко: загружаете эту папку на GitHub один раз — дальше приложение
собирается в облаке, и вы просто скачиваете готовые файлы.
Ставить Python, Android Studio и что-то компилировать не нужно.

ШАГ 1. Создать пустой репозиторий
   github.com → New repository → имя ai-marketer → Create.
   Галочки README и .gitignore НЕ ставьте: файлы уже есть в папке.

ШАГ 2. Загрузить папку
   Вариант без командной строки:
      в пустом репозитории нажмите «uploading an existing file»,
      перетащите ВСЁ содержимое папки ai_marketer_download
      (включая скрытую папку .github — от неё зависит сборка)
      и нажмите Commit changes.
   Вариант с git:
      cd ai_marketer_download
      git init
      git add .
      git commit -m "AI-маркетолог 24/7"
      git branch -M main
      git remote add origin https://github.com/ВАШ_ЛОГИН/ai-marketer.git
      git push -u origin main

ШАГ 3. Подождать 2–4 минуты
   Вкладка Actions → появятся два запуска:
      «Windows EXE»   — сборка приложения для компьютера
      «Android APK»   — сборка приложения для телефона
   Зелёная галочка = готово.

ШАГ 4. Скачать
   Откройте нужный запуск → внизу раздел Artifacts:
      AI-Marketer-Windows  → внутри AI_Marketer.exe
      AI-Marketer-Android  → внутри app-debug.apk
   Artifacts скачиваются zip-архивом (это ограничение GitHub,
   не приложения). Внутри — уже готовый файл.

ШАГ 5. Запустить
   Windows: распаковать, двойной щелчок по AI_Marketer.exe.
            Откроется консоль с адресом и браузер с формой первого запуска.
   Android: перекинуть apk на телефон, открыть, разрешить установку
            из этого источника. При первом запуске приложение спросит
            адрес кабинета — тот, что показывает программа на компьютере
            (например http://192.168.1.10:8081).

ЧТО ВАЖНО ЗНАТЬ ЗАРАНЕЕ
   • Приложение работает на компьютере, телефон открывает кабинет по сети.
     Поэтому компьютер должен быть включён, а телефон — в той же Wi-Fi.
   • Windows может спросить про брандмауэр: разрешите доступ в частных сетях.
   • .exe не подписан сертификатом, поэтому SmartScreen покажет
     «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».
   • Artifacts на GitHub хранятся 90 дней. Нужен постоянный файл —
     создайте Release и прикрепите туда AI_Marketer.exe.
   • Домены и https не нужны: приложение локальное.

ЕСЛИ СБОРКА НЕ ПРОШЛА
   • Actions → красный крестик → откройте шаг с ошибкой.
   • «gradle: command not found» — обновите workflow android-apk.yml
     (gradle/actions/setup-gradle@v3 подтягивает Gradle сам).
   • Ошибка AGP/Gradle — поменяйте в android/build.gradle версию
     com.android.application на 8.2.2 и gradle-version на 8.6.
   • Ошибка PyInstaller — выполните сборку локально: build_exe.bat
     (нужен Python с python.org), результат появится в папке dist.

ЕСЛИ НЕТ ЖЕЛАНИЯ ЗАГРУЖАТЬ НА GITHUB
   Приложение всё равно работает из исходников:
      Windows: start_one.bat  (нужен Python 3.9+)
      Телефон: start_one_phone.bat, затем открыть адрес в браузере
               и выбрать «Добавить на главный экран» — значок появится
               без сборки apk.
