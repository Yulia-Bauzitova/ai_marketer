ПРИЛОЖЕНИЕ НА ТЕЛЕФОНЕ И НА ПК
=============================

ЧТО ЭТО
   Один файл ai_marketer_one.py — внутри него сайт, кабинет, Telegram-бот,
   нейросеть, картинки, согласование и публикация. Ничего доустанавливать
   не нужно, кроме Python 3.9+ (на Windows — с python.org).

   Рядом с файлом появляются:
      ai_marketer.json   настройки (бот, ключи, компания)
      ai_marketer.db     база: задачи, знания, журнал
      media\             картинки к постам

   Данные не уходят наружу: всё лежит в этой папке.

------------------------------------------------------------------
ЗАПУСК НА ПК (Windows)
------------------------------------------------------------------
   1. Двойной щелчок: start_one.bat
   2. В консоли появится рамка с адресом, браузер откроется сам:
         http://127.0.0.1:8081
   3. Первый запуск: форма — имя бота, токен, компания, пароль.
      Токен берётся у @BotFather. Имя бота можно указать и позже.
   4. Остановить — Ctrl+C в окне консоли или закрыть окно.

   Собрать одно приложение .exe (без консоли Python, просто файл):
         build_exe.bat
      Результат: dist\AI_Marketer.exe — запускается двойным щелчком,
      рядом с ним создаются ai_marketer.json, ai_marketer.db и media\.

------------------------------------------------------------------
ТЕЛЕФОН В ТОЙ ЖЕ СЕТИ WI-FI
------------------------------------------------------------------
   1. На ПК запустите: start_one_phone.bat
      (это тот же запуск с флагом --host 0.0.0.0)
   2. В консоли будет строка «С телефона (тот же Wi-Fi): http://192.168.x.x:8081»
   3. Откройте этот адрес в браузере телефона.
   4. Windows может спросить про брандмауэр — разрешите доступ
      в частных сетях, иначе телефон не подключится.

   Важно: ПК должен быть включён — приложение работает на нём,
   телефон только открывает кабинет.

------------------------------------------------------------------
УСТАНОВКА КАК ПРИЛОЖЕНИЕ (без магазинов)
------------------------------------------------------------------
   Внутри уже есть всё для установки: манифест, иконка, офлайн-страница.

   Android (Chrome):
      меню ⋮ → «Установить приложение» или «Добавить на главный экран».
      Появится значок, приложение откроется без адресной строки.

   iPhone / iPad (Safari):
      кнопка «Поделиться» → «На экран „Домой“».

   Windows (Edge или Chrome):
      в адресной строке значок установки → «Установить».
      Приложение станет отдельным окном и пунктом в меню «Пуск».

   Ограничение, о котором нужно знать заранее: браузеры ставят
   приложение как отдельное только на https:// или на localhost.
   По адресу http://192.168.x.x установка на Android может быть
   недоступна — тогда работает обычная вкладка браузера.
   Решения: локальный https (Caddy/mkcert) или публичный домен с https.

------------------------------------------------------------------
«НАСТОЯЩИЙ» APK ДЛЯ ANDROID
------------------------------------------------------------------
   Готового APK в этой папке нет: его нельзя собрать без Android SDK,
   а у меня в среде сборки нет. Три честных варианта:

   1. PWABuilder (без программирования, 5 минут):
         • поднимите приложение на публичном https-адресе
           (VPS с доменом или туннель);
         • откройте https://www.pwabuilder.com, вставьте адрес;
         • скачайте готовый пакет Android (.apk/.aab).
      Получится оболочка, которая открывает ваш кабинет как приложение.

   2. Android Studio (WebView, 30 минут):
         новый проект Empty Views Activity → в MainActivity загрузить
         адрес вашего кабинета в WebView → Build APK.
      Нужны Android Studio и JDK, аккаунт не нужен.

   3. Только для демонстрации: «Добавить на главный экран» из Chrome —
      значок на телефоне уже выглядит и ведёт себя как приложение.

   iOS: сборка возможна только на macOS с Xcode и аккаунтом Apple
   Developer (платно). Для хакатона достаточно варианта с Safari выше.

------------------------------------------------------------------
ЧТО УМЕЕТ ПРИЛОЖЕНИЕ
------------------------------------------------------------------
   • Пост целиком: текст + картинка (обычное сообщение боту или форма в кабинете).
   • Только текст: /post тема или режим «Только текст».
   • Только картинка: /pic тема, /image, или режим «Только картинка».
   • Согласование: кнопки в боте и в кабинете.
   • Публикация в канал — только после согласования, повторно не отправится.
   • Нейросеть: облако по ключу или локальная модель (без интернета).
   • Картинки: локальная Stable Diffusion, облако или карточка бренда.
   • База знаний, журнал, состояние бота и нейросети на главной.

------------------------------------------------------------------
ЧАСТЫЕ ПРОБЛЕМЫ
------------------------------------------------------------------
   «py не является внутренней командой»
      Python не установлен или не в PATH. Поставьте с python.org
      и отметьте «Add Python to PATH».

   Бот молчит
      В настройках укажите токен, нажмите «Проверить бота».
      Ошибка 401 — токен неверный, перевыпустите у @BotFather.

   Телефон не открывает адрес
      Разные сети Wi-Fi, включён брандмауэр, или запущен start_one.bat
      вместо start_one_phone.bat.

   Порт занят
      Приложение само возьмёт следующий свободный (8082, 8083…)
      и напишет адрес в консоли.

   «Нейросеть не подключена»
      Это рабочий режим: тексты по шаблонам, картинки — карточки.
      Для нейросети впишите ключ либо поднимите локальную модель.
