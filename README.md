# AI-маркетолог 24/7

Одно приложение: сайт и кабинет, Telegram-бот, нейросеть, картинки,
согласование и публикация. Всё в одном файле `ai_marketer_one.py`.

## Скачать готовое приложение

После загрузки этого репозитория на GitHub сборка запускается сама:

| Что нужно | Где скачать |
|---|---|
| Приложение для Windows (.exe) | вкладка **Actions** → **Windows EXE** → последний запуск → **Artifacts** → `AI-Marketer-Windows` |
| Приложение для Android (.apk) | вкладка **Actions** → **Android APK** → последний запуск → **Artifacts** → `AI-Marketer-Android` |

Сборка идёт 2–4 минуты. Скачанный `.exe` запускается двойным щелчком,
`.apk` — установкой на телефон (разрешить установку из этого источника).

## Запуск из исходников (если есть Python)

```
python ai_marketer_one.py
```

Windows: `start_one.bat` (обычный запуск), `start_one_phone.bat`
(доступ с телефона по Wi-Fi), `build_exe.bat` (собрать .exe локально).

## Первый запуск

Открывается форма: имя бота, токен от @BotFather, название компании,
пароль администратора. Дальше — кабинет на `http://127.0.0.1:8081`.

## Что умеет

- пост целиком: текст и картинка;
- только текст (`/post`) и только картинка (`/pic`);
- согласование кнопками в боте и в кабинете;
- публикация в канал только после согласования, без дублей;
- нейросеть: облако по ключу или локальная модель без интернета;
- картинки: локальная Stable Diffusion, облако, карточка бренда;
- база знаний, журнал, состояние систем на главной.

Подробности — в `ПРИЛОЖЕНИЕ_НА_ТЕЛЕФОНЕ_И_ПК.txt`.
